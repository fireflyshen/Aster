# Aster · Web

Aster 的独立网页模块，支持桌面与手机。React + shadcn/ui，使用自己的依赖与构建配置；服务端复用仓库的 `src/tasks` 和 `src/connection`，默认通过 SSH 连接 RN 的 Taskwarrior。目录和运行命令继续沿用 `modules/mobile`。

## 本地运行

在 Aster 仓库根目录执行：

```sh
npm ci --prefix modules/mobile
npm run dev:mobile
```

打开 **http://localhost:4180/**。服务仅监听本机，不会安装到 RN。首次连接先确保终端能运行 `ssh rn 'task --version'`。不要用文件浏览方式直接打开 HTML，界面需要本地服务提供模块和任务接口。

```sh
npm run check:mobile
npm run test:mobile
npm run build:mobile
```

构建输出在 `dist/mobile/`，与桌面扩展的构建输出分开。模块的独立配置在 `components.json`、`vite.config.ts` 和 `tsconfig.json`；shadcn/ui 组件放在 `src/components/ui/`。

## 功能与边界

界面使用 shadcn/ui，并按用户给出的 Todoist 演示视频重做视觉：固定白色画布、红色强调色、圆形完成框、细分隔线和紧凑的属性按钮。侧栏默认收起；收件箱显示未分类任务，其下按项目折叠，搜索和视图入口放在顶部工具栏。手机使用同样的内容结构，并保留右下角添加入口。

快速添加是页面上方的浮动输入条，宽屏宽 600px，没有暗色遮罩；空白时为单行，输入后展开两行属性按钮。识别出的日期直接在输入原文中高亮，项目、日期、优先级和标签均可通过按钮调整，调整后焦点回到输入框。创建成功后显示左下角 Toast，可直接打开对应的收件箱或项目。

完整表单仍在手机使用底部 Sheet、桌面使用 Dialog；表单控件为 44px 高、16px 字号。窄屏切换为单列表单，短屏内容可滚动。长任务首行与勾选框对齐，长标签完整换行。完成任务后键盘焦点移到下一条，已完成任务保留删除线。

连接中、连接异常和待核对状态分别显示。错误后可重新加载列表而不刷新整页，快速添加草稿会保留；结果尚未确认时可先关闭编辑框检查列表。保存期间锁定全部字段，完整表单支持 **Cmd / Ctrl + Enter** 保存，任务描述中的换行转换为空格。

## 快速添加

网页获得焦点时按 **Q** 弹出快速添加，输入表达式后按 **Enter** 创建。**Shift + Enter** 换行，**Esc** 关闭并保留草稿，**/** 聚焦列表搜索；正在输入文字或使用中文输入法时不会触发页面快捷键。这是网页快捷键，系统全局快捷键仍需由桌面客户端提供。

```text
明天 交报告 #工作 @专注 p1
下周一 看完这一章 #阅读
2026-10-20 14:30 审阅设计稿 #"产品 设计" %设计 p2
Meet with Ada tomorrow at 14
```

属性用空格分隔，位置自由：

- 日期：今天、明天、后天、大后天、下周、本周一、周五、下周一、3天后、YYYY-MM-DD、due:YYYY-MM-DD，以及 today / tomorrow。未指定时间时按本机时区的当天零点写入；支持追加 `14:30`、`at 14` 或 `2pm`。
- 项目：`#项目`，带空格的名字使用 `#"项目 名称"`。
- 标签：`@标签` 或 `%标签`，多个标签自动去重。
- 优先级：`p1` → 高，`p2` → 中，`p3` → 低，`p4` → 无。

输入时直接高亮识别出的属性，并同步到下方按钮。日期旁的 × 可以保留日期词为正文；把 `"明天"` 这样的词用引号包住，也会保留为普通文字。未支持的表达式保持原文；非法日期或冲突属性会提示修正。当前不解析周期重复、提醒或任意自然语言。需要手动调整时，点「完整表单」带入全部已解析字段，已有日期时间会保留。

创建成功后关闭弹框并刷新待办列表；明确失败保留草稿供重试，结果不确定时禁用再次提交，先刷新检查，避免重复创建。

- 收件箱、今天、等待、已完成；搜索与项目筛选。
- 新建、编辑、完成、重新打开，以及确认后删除。
- 手机与桌面客户端操作同一份 RN Taskwarrior 数据；不另建数据库。
- 联网使用，不缓存私人任务，不自动重试写入。结果无法确认时先刷新检查。
- 模块独立运行，不引用其他 Flowspace 应用的域名、登录配置或部署文件。

此前的线上部署已撤销，当前没有部署脚本或线上地址。未来需要独立部署时，再配置本模块的入口和认证。已有服务器代码在生产模式下要求显式设置 `CF_ACCESS_TEAM_DOMAIN`、`CF_ACCESS_AUD` 和 `PUBLIC_ORIGIN`，不会读取其他应用的配置。
