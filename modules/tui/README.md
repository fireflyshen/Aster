# Aster TUI 工作台

独立 Go 模块，采用 Bubble Tea、Bubbles 和 Lip
Gloss；通过系统 OpenSSH 连接运行 Aster
Server 的远程主机，与 Web、MCP 和 Desktop 共享同一份 Taskwarrior 与工作区。

## 构建与安装

需要 Go 1.24+。先在终端运行
`ssh <your-vps-ssh-alias>`，确认指纹并完成密钥登录。本机不需要 Taskwarrior、Node 或新的服务端口。

```sh
cd modules/tui
go build -o ../../dist/tui/aster .
install -m 0755 ../../dist/tui/aster ~/.local/bin/aster
aster --ssh <your-vps-ssh-alias>
```

```sh
aster --ssh <your-vps-ssh-alias> --task /usr/local/bin/task \
  --taskrc /etc/taskwarrior/taskrc \
  --node /opt/aster/runtime/node \
  --socket /opt/aster/data/workspace.sock
```

`-ssh` 缺省值为 `dmit`（可通过参数覆盖为任意 SSH host alias）。`--no-color`
禁用颜色。颜色默认适配终端。当前使用 SSH 共享模式；不提供离线写入或独立本地 Taskwarrior 模式。

服务端需启用 `WORKSPACE_SOCKET`。完整功能需要部署对应版本的
[`modules/server`](../server/README.md)：提供私有任务查询、快速解析、Time 计时快照、备份导出/预览/恢复端点。遇到旧服务接口时会明确提示升级，不会绕过服务端直接改写工作区资料。

## 布局

宽屏：导航、任务区和可滚动详情。看板优先给栏目空间，Enter 可展开详情。窄屏自动收起辅助区，Tab 打开导航、Enter 查看详情，Esc 返回。底部固定显示连接、保存、冲突和错误状态。

列表分组和看板栏目共用
`board.columns`、`placements`、`order`，包括默认“未分组”和空栏目。重复任务继承系列位置。移动分组或组内位置不改变任务状态。`b`
切换布局，看板用左右键切换当前栏目。

## 操作

| 按键                   | 功能                                             |
| ---------------------- | ------------------------------------------------ |
| `Tab` / `← →` / `h l`  | 左侧导航 ↔ 右侧任务区切换（看板中切换栏目）      |
| `↑↓` / `j k`           | 选择条目                                         |
| `Enter`                | 打开项目、过滤器、详情、恢复入口或折叠分组       |
| `:` / `Ctrl+K`         | 可搜索的上下文操作菜单                           |
| `/`                    | 搜索当前视图，Enter 应用，清空后 Enter 清除      |
| `a` / `A` / `S`        | 完整添加 / 一句话捕捉 / 添加子任务               |
| `e` / `D`              | 编辑所选实体 / 快速编辑任务描述                  |
| `t`                    | 切换任务执行状态（处理中/计划中/排期/等待/搁置） |
| `x` / `s`              | 完成重开 / 开始停止计时                          |
| `!` / `@`              | 快速设置优先级 / 快速改期                        |
| `m`                    | 移动分组与组内排序，使用实体选择器               |
| `d` / `u`              | 确认删除 / 撤销最近任务操作                      |
| `p` / `n` / `g`        | 选择聚焦项目 / 设置下一步 / 新增分组             |
| `b` / `←→`             | 列表看板切换 / 选择栏目                          |
| `PgUp` / `PgDn`        | 详情滚动                                         |
| `r` / `?`              | 刷新 / 帮助                                      |
| `Esc` / `q` / `Ctrl+C` | 返回 / 退出 / 退出                               |

表单用 Tab /
Shift+Tab 切换，Enter 打开选择器或在多行文本中换行，**Ctrl+S 保存**。选择器输入搜索，标签 Enter 多选、Esc 完成；新标签也可直接输入逗号分隔文本。日期接受
`YYYY-MM-DD HH:MM`、`YYYY-MM-DD`、今天、明天；手动日期按本机时区解释，未修改的日期保留原秒数。快速捕捉使用服务端现有解析器，进入表单核对后保存。

默认首屏视图为 **「▷ 现在能做」**，按「处理中 ·
x/5」（默认展开）与「计划中」「等待中」「长期搁置」（`Space`
展开/折叠）组织，任务行徽章与详情面板显示执行态、排期、等待原因及前置依赖
`[阻塞]` 状态；触发 `409 STATE_DOING_LIMIT`
时自动弹出 5 选 1 替换选择器。内置过滤器列表已移除，习惯项目任务仅保留在专门的习惯入口而不混入普通核心视图。

项目支持点路径层级、描述、颜色、完成目标、下一步及激活/暂停/完成/重开。Focus 保持最多三个，替换通过选择器明确指定。完成项目只改组织资料，保留任务。

操作菜单提供执行状态流转、排期、前置依赖、备注增删、子任务与解除关联、任务描述、优先级与快速改期、重复规则与停止系列、自定义过滤器/标签管理、精力恢复。删除任务和停止系列都走现有恢复快照；删除项目或栏目不会删除其任务。

备份与恢复支持本地文件导出、恢复点下载、导入预览和输入 RESTORE 二次确认。导出文件权限为 0600，拒绝覆盖已有文件。恢复操作由现有服务端闸门、令牌及恢复前副本保护。

正常浏览按 10 秒自适应刷新并在 30 秒后台同步（存在运行中计时器时每秒刷新计时）；表单、错误待核对和保存期间暂停自动刷新。所有 I/O 异步执行。草稿保存在本次进程会话内，退出程序后不持久化。未知写入不自动重试，锁定后需刷新核对；组织修改使用打开表单时的 revision，冲突不覆盖其他客户端。

## 验证

```sh
go test ./...
go vet ./...
```

测试覆盖来源不匹配、未知写入、不重试、大载荷通过 stdin、栏目继承和排序、过滤保留隐藏位置、实体选择器、精确日期、revision 冲突、备份确认、中文与宽窄屏尺寸。

可用 `ASTER_PREVIEW_DIR=/absolute/path go test -run TestPreviewArtifacts`
从同一个视图渲染器输出示例 ANSI 屏幕；示例不连接远端。

## 时间线与统计视图

时间线集中呈现实际记录，不再常驻展示待开始计划。使用细线和节点连接时间记录，保持现有配色与排版。本周分布支持每日、项目、标签；成本报告支持每日、项目、标签、任务图表，并可切换时长与已确认时间成本。每日记录可以进入当天时间线。待核对记录不计入图表，标签分别累计。

图表采用 ntcharts v0.5.2，与现有 Bubble Tea v1 / Lip Gloss v1 配合。`v`
切换维度，`m` 切换指标，`Enter` 进入所选日期；报告仍支持 `w` 周/月、`o`
排序。工作区项目按点路径显示树形层级，取消“稍后”折叠分组，不改变项目或任务状态。

统计展示按数据类型选择：每日使用按日期排列的柱状图与可进入时间线的数值表；项目、标签使用横向条形比较；任务和项目成本排行将名称、图条和数值放在同一行，超预算排序时图条表示超出预算金额。统计内容限制在 88 列内，宽屏不将数值拉至面板最右侧。今日记录保留时间轴，任务、项目与管理菜单继续使用列表和属性详情。

时间统计统一使用「项目 / 标签」两个维度，默认项目。本周分布与成本报告均不提供任务或每日维度切换。时长与时间成本作为指标切换；标签包含未设标签的独立记录，多标签分别累计，不能将标签金额相加作为总额。现金汇总保留，标签不分摊现金或任务预算。
