# 时间账本界面细化

## 视觉约束

沿用 Aster 现有配色、字号、分隔线和间距。只使用低对比单色图形，不新增卡片、渐变、阴影或额外强调色。Web 与 TUI 采用相同信息组织，按各自交互方式呈现。

## 时间线

移除待开始计划的常驻列表，时间线集中呈现实际记录。保留开始、补记、确认、修正和自动停止记录的加时入口；Web 仅在主动调整一段关联记录时显示对应计划表单。

Web 用一根细竖线串起时间节点，时间位于左侧，正文位于右侧；窄屏将时间与正文折行。空白区间用空心节点弱化。TUI 以节点与连续竖线组织记录，按开始时间升序排列，保持原有选中和操作方式。

## 统计

本周分布支持每日、项目、标签，成本报告增加每日、标签图表并保留任务和项目明细。两端均支持时长与已确认时间成本切换。按日展示完整期间，包括零记录日，可进入当天时间线。

时长与成本只统计已确认事实，待核对时间保持单独显示；睡眠可有时长而成本为零。任务维度仅包含关联任务，标签分别累计并提示重叠。记录以活动 ID 和片段起止时间去重，避免任务、项目与独立记录重复入账。

Web 使用带数值的细横条；TUI 使用兼容现有 Bubble Tea v1 / Lip Gloss
v1 的 ntcharts
v0.5.2 横向条形图。每个维度共用最大刻度，零值不画实体条，保留原始数值。

TUI：`v` 切换维度，`m` 切换时长/成本，`Enter` 从每日进入时间线；成本报告继续支持
`w` 周/月、`o` 排序。

## TUI 项目树

去掉“稍后”折叠分组，不修改项目本身状态。按原生点路径排列，缺失祖先仅作为导航节点显示，使用树形连接线与短名称，保留颜色和数量。已完成项目仍只在当前查看时显示。只调整组织呈现，不改变任务状态或 UUID。
