# Aster TUI 工作台设计

## 目标

终端作为与 Web、TinyCast 并列的完整客户端。操作通过可发现的菜单、选择器和表单完成，不要求记住一排快捷键或手输 UUID、栏目名、替换项目名。数据和业务规则继续由现有 Taskwarrior 与共享工作区拥有。

## 布局与导航

宽窗口：左侧导航（视图、项目、过滤器），中间任务列表 / 看板，右侧任务或项目详情。小于 110 列收起详情，小于 76 列使用单内容区；Tab 切换导航和内容，Enter 查看详情，Esc 返回。底部固定连接、错误、保存状态及上下文提示。帮助用 ?，操作菜单用 :；菜单支持搜索。

Focus 顶部显示项目、完成目标、下一步和名额。无项目、任务已全部完成、筛选无结果、加载失败有各自的提示，加载失败不显示为零任务。

## 列表与看板统一

栏目即分组，唯一来源为 organization.board.columns；保留默认 Unsectioned。每个栏目对应一个列表分组和一列看板，顺序相同，包括空栏目。任务位置与组内排序沿用 placements/order，重复任务继承规则沿用 parent。列表组可折叠，任务菜单可选栏目、调整顺序。移动只改位置，不改任务状态。

网页列表使用同一份分组模型，可就地新增 / 改名 / 调序 / 删除栏目及移动任务；切换看板无需转换数据。搜索仅改变可见任务，不删除隐藏位置。

## 交互规范

- 表单：Tab / Shift+Tab 切换字段；Enter 在选择字段打开选择器；Ctrl+S 保存；Esc 返回并在本次会话保留草稿。
- 选择器显示名称和说明，不用自由文本代替实体选择。标签支持多选。
- 详情可滚动，长中文按终端显示宽度换行；不把完整任务塞在单行。
- 所有 I/O 使用异步命令，不阻塞按键。保存时锁定写入。
- 成功后保留当前视图和尽量保留选中任务；失败保留输入。未知结果禁止重试，刷新核对后再操作。
- 组织写入保留 revision；跨客户端冲突必须重新载入并复核。

## 服务边界与验证

补充私有 socket 的读取、快速解析、导出与备份端点；调用现有服务，复用过滤校验、日期解析、恢复闸门与共享队列，身份不匹配禁止访问。恢复操作不能在持有普通 gate lease 时等待排他恢复。旧服务端仍支持基础任务读取；新能力明确提示服务升级需求。

验收包括：列表 / 看板分组一致、搜索保留隐藏任务位置、父子任务继承栏目、键盘表单、宽/窄终端、中文换行、未知写入/冲突保护、备份预览与来源校验。使用隔离数据验证，不操作线上真实任务。
